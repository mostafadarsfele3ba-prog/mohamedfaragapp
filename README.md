# متابعة الطلاب — تطبيق المدرس وبوابة ولي الأمر

تطبيق ويب عربي يعمل على الموبايل ويُثبَّت كتطبيق (PWA). يغطي:

- المجموعات والفصول، والطلاب.
- الحضور.
- الإنذارات وسلّم التصعيد، مع التصفير الدوري.
- الإشادات، ورسائل واتساب جاهزة.
- بوابة ولي الأمر بكود الطالب.
- **تسجيل الحصص:** من داخل المجموعة ← «📅 حصة جديدة»، ولكل طالب: حضور أو غياب، حل الواجب، درجة امتحان الحصة، ملاحظات، دفع المصاريف والمبلغ. يمكن الإدخال والتعديل الجماعي لكل الطلاب أو للمحددين فقط، وكل ذلك يظهر لولي الأمر. حضور الحصة يُسجَّل تلقائياً في شاشة الحضور أيضاً.

البيانات محفوظة في Google Sheet مخفي، ولا يتعامل معه المدرس ولا ولي الأمر.

- **التكلفة:** صفر. الاستضافة على GitHub Pages، والخادم Google Apps Script.
- **بدون أي build:** ملفات HTML/JS/CSS عادية، ترفعها كما هي.
- **يعمل بدون إنترنت:** التعديلات تُحفظ على الجهاز وتُرفع تلقائياً عند رجوع الاتصال.

## إعداد نسخة لمدرس جديد (حوالي 10 دقائق)

### 1) جهّز الـ Google Sheet والـ Script
1. من حساب Google الخاص بالمدرس (أو حسابك)، أنشئ Google Sheet جديداً فارغاً وسمّه مثلاً «بيانات الطلاب — أ/ فلان».
2. من القائمة اختر **Extensions ← Apps Script**.
3. احذف أي كود موجود، والصق محتوى الملف `apps-script/Code.gs` كاملاً، ثم احفظ (Ctrl+S).
4. لا تحتاج تشغيل أي دالة: الأوراق تُنشأ تلقائياً مع أول فتح للتطبيق.

### 2) انشر الـ Script كـ Web App
1. اضغط **Deploy ← New deployment**.
2. من الترس ⚙️ اختر النوع **Web app**.
3. اضبط **Execute as: Me** و **Who has access: Anyone**.
4. اضغط **Deploy**. سيطلب Google صلاحيات: اختر الحساب، ثم **Advanced ← Go to … (unsafe) ← Allow**. هذا طبيعي لأن الـ Script خاص بك.
5. انسخ **Web app URL** (ينتهي بـ `/exec`).

> عند تعديل كود الـ Script لاحقاً: **Deploy ← Manage deployments ← ✏️ ← Version: New version ← Deploy**. بهذه الطريقة يبقى نفس الرابط.

### 3) جهّز ملفات التطبيق
1. اعمل Fork أو نسخة من هذا الريبو على GitHub، باسم مثل `teacher-ahmed`.
2. افتح `config.js` وعدّل:
   - `teacherName`، `subject`، `schoolName`
   - `apiUrl`: الرابط الذي نسخته في الخطوة 2
   - `primaryColor`، `logo` (ارفع صورة الشعار بجانب index.html واكتب اسمها هنا)، `whatsapp`
3. (اختياري) غيّر الاسم داخل `manifest.json` وأيقونات `icons/`. هذا هو الاسم الذي يظهر تحت أيقونة التطبيق على الموبايل.

### 4) فعّل GitHub Pages
1. في الريبو اختر **Settings ← Pages**.
2. اضبط **Source: Deploy from a branch**.
3. اختر **Branch: main** والمجلد **/ (root)** ثم **Save**.
4. بعد دقيقة يظهر رابط التطبيق، مثل `https://USERNAME.github.io/teacher-ahmed/`.

### 5) أول دخول
1. افتح رابط التطبيق: ستظهر شاشة **«إعداد أول مرة»** تلقائياً.
2. اختر كلمة مرور المدرس **فوراً** بعد النشر (أول من يحدد كلمة المرور هو صاحبها).
3. انتهى الإعداد. من قائمة المتصفح يمكن اختيار **«إضافة إلى الشاشة الرئيسية»** لتثبيته كتطبيق.

**رابط أولياء الأمور:** هو نفس رابط التطبيق مضافاً إليه `#/p`، وتجده أيضاً في الإعدادات. من ملف كل طالب، زر **📲 إرسال** يبعت لولي الأمر الرابط والكود جاهزين على واتساب.

## استخدام سريع
- **المجموعات:** كل مدرس يسمي مجموعاته كما يريد، فصلاً أو مجموعة درس. الطالب ينتمي لمجموعة واحدة.
- **الحضور:** اختر المجموعة والتاريخ ← اضغط «الكل حاضر» ← عدّل الاستثناءات. يُسجَّل مرة واحدة لكل طالب في اليوم.
- **الإنذارات:**
  - تسجيل الواقعة: طالب ← مستوى ← سبب، ثم زر واتساب لإبلاغ ولي الأمر.
  - حالة المتابعة تتغير من القائمة.
  - الملاحظة الخاصة 🔒 لا تظهر لولي الأمر أبداً.
- **محتاجين انتباه:** القواعد الذكية تقترح فقط. لكل اقتراح: «تطبيق» أو «تأجيل» (3 أيام) أو «رفض» (شهر).
- **الإعدادات:** المستويات والأسباب والقواعد والتصفير وقوالب الرسائل، وكلها قابلة للتعديل.

## باقي الشاشات (من قائمة ☰ المزيد)
- **الواجبات:** واجب لكل مجموعة بتاريخ تسليم ← تسجيل لكل طالب (سلّم / لم يسلّم / متأخر / بعذر) مع «الكل سلّم» وزر واتساب لمن لم يسلّم.
- **الاختبارات والدرجات:** اختبار بدرجة نهائية ← رصد سريع (اكتب الدرجة + Enter)، غياب الاختبار، المتوسط وأعلى وأقل درجة، وإرسال الدرجة لولي الأمر.
- **الجدول الأسبوعي:** مواعيد كل مجموعة (تُضبط من تعديل المجموعة)، وتظهر «مجموعات النهارده» في الرئيسية.
- **تحضير الدروس:** الأهداف والخطة والواجب وملاحظات ما بعد الحصة، مع «تم الشرح» وتحويل الواجب لواجب فعلي.
- **أدوات الفصل:** اختيار طالب عشوائي بدون تكرار، تقسيم الفصل لمجموعات، ومؤقت بتنبيه صوتي.
- **التقارير (طباعة أو PDF):** تقرير طالب، التقرير الشامل للمجموعة، كشف الحضور الشهري، كشف درجات اختبار، وأكواد أولياء الأمور. الملاحظات الخاصة لا تظهر في أي تقرير.
- **الإحصائيات:** مقارنة المجموعات، الحضور آخر 6 شهور، الغياب حسب أيام الأسبوع، ومتوسطات الاختبارات.
- **ولي الأمر** يرى أيضاً درجات الاختبارات ونسبة تسليم الواجبات.

## التحديث من نسخة أقدم
1. الصق `apps-script/Code.gs` الجديد في Apps Script واحفظ، ثم **Deploy ← Manage deployments ← ✏️ ← New version ← Deploy** (يبقى نفس الرابط).
2. ارفع ملفات التطبيق الجديدة على GitHub (مع الإبقاء على `config.js` الخاص بالمدرس).
3. الأوراق الجديدة في الشيت تُنشأ تلقائياً مع أول فتح، ولا تُمس البيانات الموجودة.

## نسيت كلمة المرور؟
1. افتح Apps Script، واختر الدالة `resetPassword` من القائمة، واضغط Run.
2. افتح التطبيق واختر كلمة مرور جديدة من شاشة «إعداد أول مرة».

## تحديث الكود
- بعد رفع تعديل على ملفات التطبيق، غيّر رقم `VERSION` في `sw.js`، مثلاً `tapp-v2`، حتى تصل التحديثات للأجهزة.
- لتشغيل اختبارات الحسابات (يتطلب Node.js): `node --test tests/logic.test.js`

---

## ⚠️ تنبيه خصوصية بيانات الطلاب
- الشيت يحتوي بيانات أطفال وأرقام هواتف أولياء أمورهم. **لا تشاركه مع أي شخص**، واتركه خاصاً بحساب المدرس.
- كلمة المرور لا تُخزَّن في الشيت ولا في الكود. يُخزَّن فقط hash مع salt داخل Script Properties.
- ولي الأمر لا يرى إلا بيانات ابنه، ولا تصله الملاحظات الخاصة ولا أرقام الهواتف. محاولات تخمين الأكواد محدودة.
- عند إرسال كود لولي الأمر، أرسله لرقمه هو فقط. لو انتشر كود طالب، اضغط «توليد جديد» من ملفه.
- «تسجيل الخروج» يمسح البيانات المحفوظة على الجهاز، فاستخدمه دائماً على الأجهزة المشتركة.
- خذ نسخة احتياطية دورياً: الإعدادات ← تصدير نسخة احتياطية.
